A clean personal command system for Ubuntu/Debian on Intel/AMD PCs.

First release · 0.4.0

Download Robot Core installer (.deb)

Install Ubuntu 24.04 or Debian 12 or newer first. This is an application installer, not a bootable OS image. New installs contain no personal workspaces or credentials.

Automatic signed updates

  1. Obtain install_release.sh and the public signing key. Confirm its fingerprint through your trusted release bundle.
  2. On the destination PC, run sudo sh install_release.sh https://wanderinginterest.github.io/robot-core-releases/
  3. The PC checks every six hours. Restart Robot Core after an update to activate it.
